# 算法原理

## 1. 问题定义

在无法直接、可靠地在线测量转子永磁体表面温度 **T15** 的条件下，利用易测的：

- 定子侧电气量：Id、Iq、Ud、Uq、转速  
- 定子侧温度：T01、T03、T08  

在 MCU 上以固定节拍在线估计 T15，供监测与保护。

## 2. 时间尺度设计

| 层级 | 周期 | 作用 |
|------|------|------|
| 调用 `rt_step` | 100 ms | 与控制器任务同拍；收最新 `u` |
| 模型步 / 特征步 | 1 s（每 10 次调用） | 匹配热过程慢动态；点采样非块平均 |
| 特征窗口 | 20 步 = 20 s | 一维 CNN 的时间感受野 |
| 输出 EWMA | τ = 1 s | 抑制量化与单步抖动 |
| 长时特征 EWMA | 30 s～7200 s | 表征热容记忆 |

首有效输出：输入就绪并完成启动等待后，需攒满 20 个模型步 → 约第 **201** 次调用（≈20.1 s）。之后每 1 s 更新网络，中间 100 ms 调用保持上一有效值。

## 3. 特征工程（56 维）

实现：`rt_features.c`，与训练用 Python **逐行对应（单精度）**。

1. **电气短时滤波**：Id/Iq/Ud/Uq τ=0.5 s，转速 τ=1 s  
2. **温度去尖刺**：因果中值(5) → 因果均值(5) → EWMA 3 s  
3. **损耗代理**（滤波后电气量）  
   - 铜耗 ∝ Id²+Iq²  
   - 铁耗 ∝ \|n\|·(Ud²+Uq²)  
   - 风摩等 ∝ n²  
   各代理再取 5 个时间常数 EWMA（30/120/600/1800/7200 s）  
4. **长时记忆**：8 路滤波量的 60/600/1800/7200 s EWMA  
5. **数据流年龄**：`1−exp(−t/2400)`，提示长时特征尚未收敛  

完整下标表见 `rt_features.h` / `rt_cnn_params.c` 文件头注释。

## 4. 网络结构（量化感知训练 → 8 bit）

窗口视为 `1×20`「图像」，56 特征为通道；卷积核 `1×3` 沿时间滑动。

```text
标准化+限幅 → 8bit 量化
  → Conv 56→16 + BN + ReLU
  → Conv 16→32 + BN + ReLU
  → GAP(20→1)
  → FC 32→32
  → FC 32→1（浮点）+ 反标准化 → ℃
```

- BN 已融合进整数偏置与移位。  
- 最后一层留在 CPU 浮点：NPU 输出仅 8 bit，直接出温度分辨率不足。  
- 定义 `RT_NPU` 时主体在片上 NPU；否则 CPU 整数路径与 NPU **逐位相同**（上电自检同时验证）。

## 5. 状态机与鲁棒性（`rt_estimator.c`）

| 机制 | 参数 | 行为 |
|------|------|------|
| 输入就绪 | 全有限且非全 0 | 未收齐 CAN 前不建窗 |
| 断流看门狗 | 12 次调用输入全不变 | 判断流，清空状态，`valid=0` |
| 启动等待 | 10 次调用 | 多帧异步到达时避免半旧半新 |
| 合理性门限 | (−60, 250) ℃ | 超界保留旧值但 `valid=0`，故障可见 |
| 复位 | `rt_reset()` / CAN `0x107` | 新数据段清空滤波器与窗口 |

## 6. 与「离线 AI」的区别（评分相关）

| 项目 | 本方案 |
|------|--------|
| 推理发生位置 | 板端 `rt_step` 实时路径 |
| 触发 | 100 ms 硬件定时 |
| 输入 | 在线 CAN 采样流 |
| 输出 | 在线 CAN 估计帧 |
| 离线部分 | 仅训练与 PC 对照生成自检向量；运行时不依赖 PC |
