## 2. 上电自检（板端 ↔ PC 同源代码）

### 2.1 方法

1. 上电执行 `board_run_boot_self_test()`。  
2. 回放 `g_board_self_test_u[221][8]`。  
3. 在第 **201 / 211 / 221** 次调用（0 基下标 200 / 210 / 220）对比 PC 期望值。  
4. 容差：`BOARD_TOLERANCE_C = 0.1 ℃`。  
5. 通过则发 CAN `0x555=1.0`。

### 2.2 固化期望点（开源可核对）

| 调用序号（1 基） | 期望 T15 ℃（PC） |
|------------------|------------------|
| 201 | 29.4496384 |
| 211 | 29.8093414 |
| 221 | 29.9735661 |

## 3. 实时在线环测试（功能）

| 步骤 | 操作 | 期望 |
|------|------|------|
| 1 | 自检通过后按信号表灌 CAN | 各 `g_can_input_frames[i]` 递增 |
| 2 | 连续有效输入 ≥ ~20 s | `g_board_last_valid=1`，`0x180` 周期出现 |
| 3 | 发送 `0x107` 复位 | 输出停发，约 20 s 后重建 |
| 4 | 人为停发输入 >1.2 s（保持末值不变） | 断流看门狗触发，`valid=0` |
| 5 | 可选发 `0x106` 真值 | `0x181` 转发，且不改变模型输入 |
